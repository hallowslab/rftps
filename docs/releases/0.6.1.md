Bugfix release — dependency refresh with no breaking API changes.

### Changes

- **Dependency refresh** to latest versions, including the major bumps:
  - `suppaftp` 8 → 10
  - `reqwest` 0.12 → 0.13 (rustls backend, `rustls-no-provider`)
  - `ed25519-dalek` 2 → 3
  - `webpki-roots` 0.26 → 1.0
  - `rand` / `rand_core` 0.6 → 0.10
  - `aws-sdk-s3` → 1.141, `clap` 4.6, `tokio` 1.53, `rcgen` 0.14 (dev)
- **Key generation reworked** for `rand_core` 0.10: device-key generation now uses `SysRng` (`rand::rngs`) wrapped in `rand_core::UnwrapErr`, replacing the removed `OsRng`
- **aws-sdk-s3** built with default features disabled — smaller binaries, fewer transitive dependencies

### Notes

- Behavior and CLI unchanged; existing configs keep working
