## rftps v0.6.0

Major feature release — background jobs, pluggable storage, and broker replication.

### Background job system
- Event bus with typed FTP events (logins, uploads, downloads, renames, deletes, directory changes)
- In-memory job queue, worker pool, scheduler, and worker traits
- `background-jobs` feature gate

### Pluggable storage backends
- `StorageBackend` trait with a `StorageBackendFactory`
- **FTPS backend**: secure transfers with custom CA / embedded-PEM support and optional cert-verification bypass
- **S3 backend**: AWS S3 storage (MinIO-compatible, path-style, custom CA)
- `NoCertificateVerification` helper for dev/testing
- Self-signed certificate generation example (`gen_cert`)

### Broker replication
- Broker (relay) client and backend for centrally-managed credentials and device approval
- Ed25519 device keys, key generation, and `broker keygen` / `broker init` / `broker pubkey` commands
- Replaces the earlier relay implementation in the background-job configuration
- `passive_ports` / `external_ip` server options

### CI / testing
- CI now tests and builds both the plain and full (s3 + broker) feature variants
- Extensive test coverage for storage, broker backend, job queue, event bus, and TLS
- Broader test suite overall
